Decided: **APPROVED WITH MODIFICATIONS** — `coder` (Pipeline Phase 5) may proceed, with
nine binding conditions on `Delivers:`/`Done when:` before planning.
Why: the task is architecturally sound (no protected contract touched, node discovery is
by convention so no `src/graph/` edit is needed, module DAG unchanged), but it inherits
four already-landed consumer contracts its own `Delivers:` list does not mention.
Affects: `src/nodes/llm/coder.py` (new), `config/agents/coder.yaml`, `config/prompts/coder/v1.md`,
`docs/pipeline.md`, `docs/agents.md`, `tests/fixtures/graph_mocks.py` (phase5 seeding).
Discarded: blocking T-029 on the ML-dependency gap (8 of 18 model families have no installed
library) — that is `pyproject.toml`, infra-agent's folder, and would stall the critical path.

### Conditions (all must land in the T-029 PR)

1. `submission.csv` added to `Delivers:` and `Done when:` — `kaggle_client` (T-033, landed)
   submits exactly `{best_experiment_path}/submission.csv` and synthesizes nothing.
2. Experiment-directory stability across `code_critic` retries must be an explicit,
   documented decision. Ruling: **overwrite `experiments/exp_{current_iteration}/` in place**
   on every retry, and record the *directory* (not a file) in `state["experiments"][-1]["path"]`.
3. `state["experiments"]` is a plain `LastValue` channel with **no reducer** — "appends"
   means read-copy-append-return-whole-list, not return-a-one-element-list.
4. `results.json` must carry `oof_path`, or the OOF file must be named
   `oof_predictions.parquet` inside the experiment directory (`ensemble_specialist`, T-028).
5. Column names from `feature_spec.json` must be emitted via `repr()`/`json.dumps` or
   indexed through a variable — never concatenated into a quoted Python literal.
6. A Done-when assertion that a second invocation carrying an `iterate` verdict message
   produces *different* output (T-030's feedback channel is `state["messages"]` only).
7. `docs/pipeline.md` added to `Done when:` alongside `docs/agents.md`.
8. The execution-retry bound is a module-level constant in `coder.py` — `AgentConfig`
   silently drops unknown agent-YAML keys, and `config/settings.yaml` / `src/config/`
   are protected contracts outside this task's `folders:`.
9. Phase 5's entry in `tests/integration/phases/test_phase_subgraphs_smoke.py` runs
   `code_executor` for real; the mocked `coder` response must emit a trivially fast
   script and the phase must seed `data/raw/`, `fold_config.json`, `design.json`,
   `feature_spec.json`.
