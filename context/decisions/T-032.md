## 2026-08-18 — T-032 [pipeline-agent]
Decided: all three nodes override `_resolve_output_path` to interpolate the coerced
`_evaluation_llm_common.current_iteration(state)` rather than inheriting `LLMNode`'s raw
`state["current_iteration"]` read.
Why: each artifact injects its own `iteration` field from the coerced helper (`bool` rejected,
non-`int` defaulted to `0`). Without the override a non-integer `current_iteration` — which
LangGraph does not prevent, since it does not enforce the `LabState` TypedDict at runtime — would
file `reports/experiment_plan_True.json` containing `"iteration": 0`, and `experiment_designer`
would increment `True + 1 == 2`. The filename number and the recorded number must never disagree.
`_resolve_output_path` is a documented `LLMNode` extension point, so this needs no change to
`base.py`.
Affects: `src/nodes/llm/error_analyst.py`, `src/nodes/llm/hypothesis_generator.py`,
`src/nodes/llm/experiment_designer.py`.
Discarded: leaving the base implementation and accepting the mismatch.
