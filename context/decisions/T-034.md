## 2026-09-12 — T-034 [Architect]
Decided: APPROVED with conditions. Nine rulings fixing the `src/api/` ↔ `src/graph/` integration
contract, recorded here because `src/api/` is greenfield and T-035/T-036/T-037/T-043 all inherit them.
Why: see each item.
Affects: `src/api/main.py`, `src/api/routers/runs.py`, `docs/api.md`, `design.md` (§ Checkpointer),
`docs/adr/0001-run-registry-on-disk.md`, `frontend/src/api/types.ts` (via discovery, not edited here).

1. **Run registry on disk** — `runs/{run_id}/run.json` sidecar, `GET /api/runs` scans it.
   Why: an in-memory dict passes every acceptance criterion while voiding design.md's Availability
   NFR — a checkpoint that survives restart becomes unreachable because no endpoint lists it.
   Full reasoning in ADR 0001. Discarded: in-memory `dict[str, RunRecord]`; a cross-run SQLite index
   (second schema to own, no benefit at single-user scale).

2. **The blocking graph runs off the event loop** — `await asyncio.to_thread(graph.invoke, …)` inside
   the background task, never `graph.invoke(…)` directly in the coroutine.
   Why: `GraphBuilder.build()` returns a graph whose phase wrapper (`_wrap_phase` in
   `src/graph/builder.py`) calls the **synchronous** `compiled.invoke(state)`, and the nodes under it
   make blocking LLM calls. Awaiting that on the event loop freezes every other endpoint for the
   length of a run (hours, per design.md's Latency NFR) — `GET /api/runs` would hang and T-035's SSE
   stream would never flush. `check_same_thread=False` is already set in
   `src/graph/checkpointer.py`, so the worker thread is safe.

3. **Thread config is nested** — `{"configurable": {"thread_id": run_id}}`.
   Why: design.md line 388 showed a bare `{"thread_id": run_id}`, which LangGraph ignores; the run
   would start a fresh unnamed thread and resume would silently never find the interrupt. design.md
   corrected in this task.

4. **Resume = `update_state` then `invoke(None)`** — write `human_feedback` via
   `graph.update_state(config, {"human_feedback": …})`, then resume with `graph.invoke(None, config)`.
   Why: `human_feedback` is a plain LastValue channel with no reducer; passing it as fresh input to an
   interrupted thread is not the documented resume path. 404 when no checkpoint exists for the id,
   409 when the run is not actually interrupted.

5. **`best_score` serializes as `null` when it is `-inf`.**
   Why: `src/state.py::new_state` seeds `best_score=float("-inf")`. FastAPI's plain-dict path
   (`jsonable_encoder` → `json.dumps`) emits the non-standard token `-Infinity`, which
   `JSON.parse` rejects — every `GET /api/runs/{id}` on a fresh run would break the frontend.
   Declared Pydantic response models avoid it (pydantic 2.12 defaults `ser_json_inf_nan='null'`),
   which is why response models are required rather than optional. Must be asserted by a test.

6. **Response keys are snake_case, matching `LabState`; status values are taken verbatim from the
   frontend's provisional `RunStatus`** (`pending|running|interrupted|completed|failed`).
   Why: `frontend/src/api/types.ts` guessed camelCase (`currentIteration`, `humanFeedback`) while this
   task's own acceptance criteria pin `phase`, `current_iteration` and `{"feedback": …}`. The backend
   is authoritative — the frontend types were explicitly marked provisional pending exactly this.
   Adopting the guessed status vocabulary costs nothing and spares a second reconciliation.

7. **`JsonlCallbackHandler` is attached at invocation** — `config["callbacks"] = [JsonlCallbackHandler(run_id, runs_dir)]`.
   Why: T-012 landed the handler with **no caller anywhere in `src/`**. The API is the only code path
   that ever holds a `run_id` at invocation time, so if T-034 does not attach it, `execution.jsonl` is
   never written, the module stays dead, and T-035 has no on-disk event source to fall back on.

8. **Single active run enforced with 409.**
   Why: design.md's Concurrency NFR is "single user, single active run at a time", and invariant #6
   (max 2 concurrent LLM agents) is enforced per-run inside the pipeline — two concurrent runs would
   silently double it.

9. **`runs/` is not the workspace.** `src/api/` writes `run.json` there directly without
   `WorkspaceManager`; invariant #2 governs `~/competitions/{name}/` only, where `WorkspaceManager`
   remains mandatory. Stated explicitly so reviewers do not read the sidecar write as a violation.

Discarded overall: deferring the registry-shape question to T-035. Four downstream tasks depend on
`src/api/` and none of them owns the shape; leaving it implicit would have each of them invent one.
