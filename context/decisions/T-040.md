## 2026-09-13 — T-040 [architect]

pre-baseline.

## 2026-09-13 — T-040 [architect]
Decided: higher-is-better throughout — `delta = cv_score - baselineScore` (positive =
improvement), and "best" is derived as **max `cv_score`**, ties broken by lowest
iteration. No `bestExperimentPath` prop.
Why: critical invariant #3 (`best_score` updates only on improvement) and
`src/state.py`'s `best_score=float("-inf")` seed both encode a strictly
higher-is-better comparison system-wide; no field anywhere in `LabState` records
metric direction, so there is nothing to branch on and a direction prop would be an
unsourced invention. Deriving best from the rows keeps the component's highlight
consistent with the same rule the pipeline uses.
Affects: frontend/src/components/ExperimentsTable.tsx.
Discarded: a `metricDirection` prop — no producer for it anywhere in the system.
