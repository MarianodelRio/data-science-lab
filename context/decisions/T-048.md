## 2026-09-14 — T-048 [Architect]
Decided: `validate_required_keys()` is a **classmethod** preflight
(`Settings.validate_required_keys(path=SETTINGS_PATH) -> None`), not an instance
method on a loaded `Settings`.
Why: `_resolve_env_vars` (src/config/settings.py:42-45) already raises
`ConfigError` for a missing **and** for a set-but-empty `${VAR}`. A `Settings`
instance therefore cannot exist with an empty API key — an instance method
checking for one would be unreachable code that can never fail. The real gap is
that nothing calls `Settings.load()` at boot (only `src/llm/factory.py:95` and
per-node call sites, all lazy), so the preflight must be callable *before* a
successful load.
Discarded: `settings.validate_required_keys()` as an instance method — dead code.

## 2026-09-14 — T-048 [Architect]
Decided: the required-key set is exactly the fields of `ApiKeysConfig`
(`anthropic`, `deepseek`, `groq`, `kaggle_username`, `kaggle_key`), derived by
reflection over `dataclasses.fields(ApiKeysConfig)` rather than a second
hardcoded list.
Why: preflight must require **exactly** what `Settings.load()` already requires —
no more, no less. Narrower lets boot succeed and the run die later, defeating the
purpose; wider blocks boots that work today (L-007: an over-matching validator
whose exception nothing catches kills the run, and the two error directions are
not symmetric). Reflection keeps one source of truth, so a future `openai`/
`gemini` field becomes required automatically.
Discarded: deriving the set from `models.{role}.provider` or from `LLMFactory`'s
provider dispatch — would invert the dependency direction (`src/config/` is a
leaf importing only stdlib + yaml) and would silently under-require the Kaggle
credentials, which no `models` role references.

## 2026-09-14 — T-048 [Architect]
Decided: `Dockerfile.api` line 12 (`pip install torch --index-url
https://download.pytorch.org/whl/cpu`) is **kept unchanged**; the task's
"simplify Dockerfile.api's install step if it becomes redundant" is declined.

outside T-048's declared `folders:`.
