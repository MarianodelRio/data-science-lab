## 2026-09-14 — T-049 [Architect]
Decided: `Settings.validate_required_keys()` is wired via a **new injection
seam** on `create_app` (`key_validator: Callable[[], None] | None = None`,
defaulting to `Settings.validate_required_keys`), invoked from a FastAPI
**lifespan startup handler** — never from `create_app`'s body, and never at
module import.
Why: `src/api/main.py:173` runs `app = create_app()` at import time, and
`tests/unit/api/conftest.py:51` enters `with TestClient(app)`, which executes the
ASGI lifespan for every API unit test. CI (`.github/workflows/ci.yml`) sets no
`ANTHROPIC_API_KEY`/`DEEPSEEK_API_KEY`/`GROQ_API_KEY`/`KAGGLE_*` env vars and no
conftest provides them, so an un-injectable validator on either path turns the
whole `tests/unit/api/` suite red. Body-of-`create_app` placement additionally
breaks import (mypy, pytest collection), which is worse than a failed startup.
The seam mirrors the four seams `create_app` already has (`graph_factory`,
`explainer_factory`, `rag_store_factory`, `mlflow_url`), so no new pattern is
introduced. Existing `tests/unit/api/` fixtures inject a no-op validator; the
integration test for "fails to start with a clear error" injects the real
classmethod against a `tmp_path` settings.yaml.
Discarded: calling it unconditionally in the lifespan with tests setting fake env
vars — makes every future api test depend on ambient environment, and the real
`SETTINGS_PATH` default would still read the repo's live `config/settings.yaml`.

`context/discoveries/T-040.md` verbatim.

## 2026-09-14 — T-049 [Architect]
Decided: `baseline_score` serializes as **`null` whenever the run has not yet
produced a baseline**, detected via empty `baseline_results_path` (or an empty
checkpoint values dict) — never as the raw `0.0` seed.
Why: `src/state.py:91` seeds `baseline_score=0.0`, a legitimate score, so the
seed is not a sentinel (L-019, raised on this exact field during T-040). Passing
`0.0` through makes `ExperimentsTable` render a fabricated delta equal to each
raw CV score. `baseline_results_path` (`src/state.py:41`, seeded `""`, set once
when the baseline runs) is the unambiguous discriminator. The Pydantic response
model must carry `model_config = ConfigDict(ser_json_inf_nan="null")` and be
emitted through `src/api/responses.py::json_response`, per the `-Infinity`
hazard documented in `src/api/models.py`.

## 2026-09-14 — T-049 [Architect]
Decided: the `id`-uniqueness requirement is satisfied by **passing
`LabState.experiments` through unchanged** and documenting the guarantee, not by
server-side rewriting or de-duplication of ids.
Why: `src/nodes/llm/coder.py:449-461` is the sole writer of `experiments` in
`src/` (verified by grep), it assigns `id = f"exp_{iteration}"`, and
`coder.py:43-53` documents that exactly one entry is appended per graph-level
iteration regardless of internal or `code_critic` retries. Ids are therefore
already unique by construction. Rewriting them in the API would break the
`id` ↔ `experiments/exp_{N}/` directory correspondence that
`ensemble_specialist`, `error_analyst` and `_experiment_design` rely on, and
would put the API in the business of repairing pipeline state it does not own.
The endpoint must not silently drop or renumber duplicates either — a duplicate
id would be a pipeline bug, and hiding it at the HTTP boundary would make it
undiagnosable.

## 2026-09-14 — T-049 [Architect]
Decided: the file-content endpoint uses **`WorkspaceManager.read_text` as-is**.
No method is added to `WorkspaceManager`, so its protected public API is
untouched and no human approval for a contract change is required.
Why: `WorkspaceManager._resolve` (`src/workspace/workspace_manager.py:33-43`)
already rejects empty/`.`, absolute, and `..`-containing relative paths with
`ValueError`, which is exactly the guard the Done-when criterion asks for.
`read_text` returns the content. Mapping: `ValueError` → 400 (rejected path),
`FileNotFoundError`/`IsADirectoryError` → 404, `UnicodeDecodeError` → 415 or 400
(binary file is not serveable as text). Run the whole resolve+read through
`asyncio.to_thread` — `WorkspaceManager.__init__` does
`mkdir(parents=True, exist_ok=True)` plus blocking disk reads, the same
constraint already documented at `src/api/routers/kaggle.py:53-70`.
