(src/state.py:39,45). The full route surface today is `POST /api/runs`,
`GET /api/runs`, `GET /api/runs/{id}`, `GET /api/runs/{id}/events` (SSE),

`baselineScore?: number | null`), but it is inert in the running app: `Layout.tsx`
renders it with no props, so it always shows its "No experiments yet." no-data
state until a real data source exists.
